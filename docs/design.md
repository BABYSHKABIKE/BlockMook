# Решения интерфейса

BlockMook — небольшое приложение с одной основной задачей. Главный экран отдаёт приоритет состоянию подключения, действию и выбору сервисов. Диагностика и источник компонентов остаются доступны без заполнения главного экрана техническими надписями.

- Чёрные и графитовые поверхности, светлая типографика, полупрозрачные кнопки Tiffany. Цвет не заливает большие области экрана.
- Собственный геометрический знак: разомкнутая буква B. Один вектор используется в приложении, трее, ярлыке и документации; ICO содержит семь размеров от 16 до 256 пикселей.
- Постоянная навигация: подключение, диагностика, сеть и обновления сверху, настройки и информация снизу.
- Нейтральные заголовки и конкретные статусы. Без слоганов и обращения на «ты». Инструкции появляются там, где требуется действие; повторяющие названия кнопок подписи исключены.
- Состояние всегда подписано текстом. Цвет сам по себе не сообщает об успехе проверки.
- Изменение сервисов и стратегии заблокировано во время подключения, чтобы экран не обещал уже применённые настройки.
- Модальное знакомство блокирует фон, поддерживает клавиатуру и пропуск; его можно открыть повторно.
- Переходы 140 мс; опция уменьшения анимации отключает их.
- Проверки, ошибки и загрузки не блокируют поток интерфейса. Прерывание загрузки не сохраняет повреждённый ZIP как готовый.

Ориентиры: [иерархия и отступы Windows](https://learn.microsoft.com/en-us/windows/apps/design/basics/content-basics), [навигация](https://learn.microsoft.com/en-us/windows/apps/design/basics/navigation-basics). Стиль BlockMook разработан в коде WPF; это не копия чужого макета.

Проверять обычное и минимальное окно, ручной выбор, первый запуск, доступность с клавиатуры, частичный доступ, отмену, отсутствие релиза и ошибки скачивания. Для обновлений используется [GitHub Releases API](https://docs.github.com/en/rest/releases/assets); SHA-256 берётся из `digest` метаданных опубликованного файла.
