# Сеть

**BlockMook 1.0.** Установщик различает сборки по SHA-256 исполняемого файла и сохраняет предыдущую папку.

## Управление

Открой раздел «Сеть»: показатели доступны только внутри приложения. Оверлей, его настройки, меню трея и глобальные горячие клавиши удалены.

## Значения

- Скорость — разница счётчиков одного сетевого адаптера за фактическое время между измерениями. Единицы автоматически выбираются по величине: бит/с → Кбит/с → Мбит/с → Гбит/с (либо Б/с → КБ/с → МБ/с → ГБ/с). Десятичный шаг — 1000, 1 МБ/с = 8 Мбит/с. Число округляется до целого в выбранных единицах: 1 Кбит/с, 30 Мбит/с. Малый ненулевой трафик не превращается в «0,00 Мбит/с»; график использует исходные неокруглённые значения. Это текущий трафик, а не максимальная скорость тарифа. Первый отсчёт, сброс счётчиков и длительная пауза дают «—».
- Автовыбор предпочитает активный Ethernet/Wi-Fi с шлюзом. Можно выбрать адаптер вручную, в том числе виртуальный; счётчики нескольких адаптеров не суммируются. Список адаптеров формируется при запуске приложения.
- Пинг — одна ICMP-проба в секунду с тайм-аутом 900 мс. По умолчанию адрес 1.1.1.1 (Cloudflare), можно ввести другой IPv4/IPv6. Запрос идёт по маршруту Windows, а не принудительно через адаптер счётчиков; активный VPN может влиять на него. Адрес показан рядом с измерениями.
- Потери — доля проб без успешного ответа за последние 60 секунд, рядом указано число проб. Если измерений нет — «—», а не 0%. Ошибка самого измерителя не считается потерянным пакетом.
- Колебания — средняя абсолютная разница соседних успешных ответов за минуту. Через тайм-ауты пары не образуются. ICMP-статистика не доказывает потери или задержку игрового трафика.
- График показывает последние 60 секунд: загрузка цветом текста, отдача белым. Общая вертикальная шкала автоматически подстраивается под максимум двух рядов; пропуски не соединяются линией.

Измерения выполняются только когда раздел «Сеть» открыт в видимом, не свёрнутом главном окне. При уходе на другую страницу, сворачивании или скрытии в трей таймер останавливается, история измерений сбрасывается. Уже начатая проба может завершаться до 900 мс после скрытия; её результат не применяется.

История — последние 100 событий подключения в оперативной памяти; очищается кнопкой или после полного выхода. Постоянного журнала этих событий нет.

## Настройки и совместимость

Адрес пинга, адаптер и единицы скорости сохраняются в `%LOCALAPPDATA%\BlockMook\network-v1.txt` и проверяемой копии `.tmp`. Если нового файла ещё нет, из прежнего `overlay-v1.txt` читаются только эти три настройки. Параметры включения, горячей клавиши и отдельного окна игнорируются. Старый файл сохраняется для восстановления предыдущей сборки.

Две копии с SHA-256 и принудительным завершением записи позволяют восстановиться после прерывания записи без переименования EFS-файлов и снятия шифрования.

Удаление оверлея не означает подтверждённую совместимость с античитами: сетевой компонент WinDivert остаётся частью подключения. См. [ограничения совместимости](anticheat.md).
